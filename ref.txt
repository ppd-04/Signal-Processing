CREATING ARRAYS
np.linspace(start, stop, N)   → N floats from start to stop (includes stop)
np.arange(start, stop)        → integers from start to stop-1
np.zeros(N)                   → N zeros
np.zeros_like(arr)            → zeros, same size as arr
np.full_like(arr, np.nan)     → NaN, same size as arr

INDEXING
arr[0]       → first element
arr[-1]      → last element
arr[::-1]    → reversed array          ← TIME REVERSAL
arr[2:5]     → elements at 2,3,4
arr[mask]    → keep only True positions

MATH
np.abs(arr)         → absolute value of every element
np.floor(x)         → round DOWN   (-1.3 → -2)
np.ceil(x)          → round UP     (-1.3 → -1)
round(x)            → round to nearest integer
int(x)              → cut off decimal (towards zero)
np.clip(x, a, b)    → keep x within [a, b]
np.sqrt(arr)        → square root
np.sin(arr)         → sine (input in radians)
np.cos(arr)         → cosine
np.pi               → 3.14159...

OPERATIONS (all element-wise)
arr + arr2    arr - arr2    arr * arr2    arr / arr2
arr ** 2      arr * 5       arr / 2       arr + 100
n % k         → remainder   (6%3=0, 7%3=1)
n // k        → integer division (7//3=2)

CONDITIONS (use & and |, NOT and/or for arrays)
arr >= 0               → True/False array
(arr >= 0) & (arr <= 4)  → AND
(arr < 0)  | (arr > 4)   → OR

STATISTICS
np.sum(arr)    np.mean(arr)    np.max(arr)    np.min(arr)
np.mean((a-b)**2)   → MSE between a and b

USEFUL
np.isclose(a, b)     → True if nearly equal (handles float errors)
np.allclose(a, b)    → True if ALL elements nearly equal
np.where(cond, a, b) → element-wise if-else
len(arr)             → number of elements

SINUSOID
x[n] = A * np.cos(Omega0 * n + phi)
time shift:   A * np.cos(Omega0 * (n - n0) + phi)
phase change: A * np.cos(Omega0 * n + phi + phi0)
RELATIONSHIP: phi0 = -Omega0 * n0

DISCRETE TIME REVERSAL

DISCRETE TIME SCALING y[n] = x[n/k]
result = np.zeros(2*INF + 1)
for p_out in range(2*INF + 1):
    n = p_out - INF
    if n % k == 0:
        n_over_k = n // k
        p_in = n_over_k + INF
        if 0 <= p_in <= 2*INF:
            result[p_out] = x[p_in]

WITH INTERPOLATION (when n%k != 0):
    left_n  = int(np.floor(n/k))
    right_n = int(np.ceil(n/k))
    left_val  = x[left_n  + INF] if -INF <= left_n  <= INF else 0
    right_val = x[right_n + INF] if -INF <= right_n <= INF else 0
    result[p_out] = (left_val + right_val) / 2
